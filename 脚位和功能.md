### 脚位和功能
| 引脚编号 | 名称       | 功能                                                                                             |
| -------- | ---------- | ------------------------------------------------------------------------------------------------ |
| 1        | vcc        | -                                                                                                |
| 2        | PA7        | 滚珠检测（外部有上拉，有震动时，检测到高电平，没有震动时，检测到低电平；建议检测时采用边沿检测） |
| 3        | PA6        | 开关，控制笔头ic的供电                                                                           |
| 4        | PA5  (VPP) | 充电检测                                                                                         |
| 5        | PA2        | LED控制（A端）                                                                                   |
| 6        | PA1 (SDA)  | LED控制（B端）                                                                                   |
| 7        | PA0 (SCK)  | LED控制（按键检测、LED公共端）                                                                   |
| 8        | GND        | -                                                                                                |


测试时，可以用仿真板的PA7作为串口发送脚，PC1作为IO翻转
